# 実験13 設計提案:「persona らしさ」と「表層反応」の分離

**状態**: 提案(2026-11-06)。凍結・生成は未実施。E10-12 の成果物は不変。

## 0. 動機

E12 で Llama は「指示 family × 証拠層に条件付けられた応答方針」を
示したが、それが安定的な応答プロファイル(persona 的)なのか、
指示語彙への表層反応なのかは未分離。E13 はこの2説明を対立させる。

- **説A(表層反応)**: 「withhold せよ」「確言せよ」等の語彙そのものが
  対応コードを誘導しているだけ。語彙を入れ替えても同じ条件付けが
  残るなら表層ではない。
- **説B(方針的条件付け)**: 指示の機能的役割(慎重/確言/辞退可能)に
  応答が条件付けられている。言い換えに頑健なら方針レベル。

## 1. 介入設計(対照条件の導入)

E12 の10設定を基盤に、3つの対照 family を追加(各2パラフレーズ):

- **lexical-swap**: cautious/confident と同じ機能的指示を、
  rubric コード語彙(withhold/support/decline 等)を避けた別表現で書く。
  例:「結論を保留せよ」→「観察が許す範囲だけを述べよ」。
  予測: 説A なら構成が大きく変わり、説B なら類似分布が残る。
- **misleading-gloss**: 機能的に逆の語彙で同じ役割を指示する
  (例:confident 系文面で慎重判断を求める)。表層に引っ張られる
  なら分布が語彙側に倒れる。
- **named-role**: 「Morgan」でなく別名の回答者(例:「Alex」「Dr. Chen」)
  に同じ指示を当てる。名前依存か役割依存かの切り分け。

合計 10+6=16設定 × 2 replicate。

## 2. 主比較(案)

- **主**: lexical-swap セルと対応する正本セルの構成分布の一致度
  (セル間 JS divergence を質問加重平均)。一致が高い=説B 支持。
- **補助**: named-role vs Morgan の同指標、misleading-gloss が語彙側に
  倒れる度合い、E12 の構成予測器を新条件に外挿した場合の Brier。
- 閾値は凍結時に設定(E12 同様、事前指定必須)。

## 3. 留保・コスト

- 設定 16 × 48題 × 2 = 1,536 eval 生成/モデル、dev 52×16×2=1,664/モデル。
  ラベルは dev 3,328 + eval 3,072 = 約 6,400/モデル。前回(E12)より重い。
- 「説B が残る」でも persona の実在は主張しない — 主張は「応答方針が
  語彙に頑健」に留める。
- 代替案: 人間観察者導入は独立課題で、E13 とは別に進められる。
